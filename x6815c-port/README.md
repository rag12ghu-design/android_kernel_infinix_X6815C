# X6815C source-port support files

This directory contains the patches, probe-only configuration fragments, build scripts, audit reports, and provenance for the experimental Infinix Zero 5G 2023 (X6815C) MT6877 source port.

Start with [`../X6815C-PORT.md`](../X6815C-PORT.md) and [`FINAL-REPORT.md`](FINAL-REPORT.md).

No file in this repository is a flashable boot image. The successful build probe deliberately disables unavailable X6815C camera kernel drivers and is not stock-equivalent or device-tested.
